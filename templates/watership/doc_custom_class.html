Compare

with compare you can define comparison method. By defining compare function you can compare objects like numbers and sort them

$Person
&+string:name
&+int:age
#type is this class's type. in this case "Person"
#other object must be same or inheritance of current class
@compare(type:other):int
    &if (age > other:age)
    &return:1
    &elif (age < other:age)
    &return:-1
    &elif (age == other.age)
    &return:0
    &endif
$Person

&Person("Alice", 21):alice
&Person("Bob", 20):bob
&if(alice > bob)c#automatically calls compare function
&print:Alice is older than Bob \n
&elif(alice < bob)
&print:Bob is older than Alice \n
&elif(alice == bob)
&print:Bob and Alice are same age\n
&endif

Expected output

Alice is older than Bob

Convert

$Imperial
&+float:weight
&+float:temperature
@constructer(float:_weight, float:_temperature)
    &weight = _weight
    &temperature = _temperature
@constructer
@convert():Metric
    &return:Metric(weight/2.2, (temperature - 32)*5/9)   
@convert
@convert():string
    &return:"":weight\: : {weight} : temp\: : {temperature} 
@convert
$Imperial

$Metric
&+float:weight
&+float:temperature
@constructer(float:_weight, float:_temperature)
    &weight = _weight
    &temperature = _temperature
@constructer
@convert():string
    &return:"":weight\: : {weight} : temp\: : {temperature} 
@convert
$Metric

&Metric:metric_obj
&Imperial:imperial_obj(45, 70.5)
&metric_obj = imperial_obj automatically calls convert function
&print:imperial obj is :{imperial_obj}:\n #automatically calls format convert string function
&print:metric obj is :{metric_obj}

Expected output

imperial obj is  weight: 45 temp: 70.5
metric obj is weight: 20.4117 temp: 21.388

Note: {<object_name>} or assigning object to string type object will automatically call convert string function. if string conversion is not defined then by default it will convert to string "<object_name>"
