Variable Types

Syntax

Variable type is simply referred as "type" and instance created from type is referred as "object"

&<type>:<object_name> = <value>
&int:a = 13 #declare integer
&float:f = 3.14 #declare float
&bool:b = T #T is True | F is false
&string:s = "Hello world" #declare string
#variable printing example
&print:integer :{a}:\n
&print:float :{f}:\n
&print:bool :{b}:\n
&print:string :{s}:\n

Expected output

integer 13
float 3.14
bool True
string Hello world

Like in C/C++ Watership has pointer type variable

pointers example

&int:a = 0 #declare integer
&pointer:addr = a #assign address of an a
&pointer:value   #returns a value of object
&pointer:value = 12 #assigns new value to address of an a
&print:value of a is :{a}
Expected value 
value of a is 12
