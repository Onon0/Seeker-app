Arrays and Collections

Syntax

&Array<type>[size][size] ... [size]

Arrays

Arrays are static multidimensional collection

Basic Array example

&Array<string>[3]:arr = ["apple","banana","kiwi"]

2d array example

&Array<int>[3][2]:arr = [[1,2],[3,4],[5,6]]

List

List is dynamic one dimensional collection that follows FILO principles

List syntax

&List<type>:lst
&lst:append(<object>)
&lst:+<object>#alternative syntax for append
&lst:pop #returns first object (removes object from list)

Stack

Stacks are dynamic one dimensional collection that follows FIFO principles

Stack syntax

&Stack<type>:stk;
&stk:append(<object>) #add new variable 
&stk:+<object> #alternative syntax for append
&stk:pop #returns last object (removes object from list)
