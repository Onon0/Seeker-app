Classes and Objects

Syntax

$class_name denotes start and end of class definition. "+" sign before declaration marks it's public member and "-" sign marks private member.

$<class_name>
&+<public variable declaration>
&-<private variable declaration>
@constructer...
@+<function1... >#public function
@-<function2... >#private function

$<class_name>

Basic example

$Person
&+string:name
&-int:age
#constructer is special function name for initializes object
#constructer() is considered default
@constructer() 
&name = "John Doe"
&age = 10
@constructer(string:_name, int:_age) #multiple constructers with different definitions are allowed
    &name = _name
    &age = _age

@+set_age(int:_age)
    &age = _age 
@set_age

@+get_age()
    &return:age
@get_age
$Person

&Person:person1 default constructor will be called
&Person("Mary Sue", 20):person2

&print:{person1:name}: is :{person1:get_age()}: years old \n
&print:{person2:name}: is :{person2:get_age()}: years old

Expected output

John Doe is 10 years old
Mary Sue is 20 years old
