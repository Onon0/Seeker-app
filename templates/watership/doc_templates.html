Class Templates

You can change variable types using template specification just like in C++

Syntax

$<class_name><T1, T2>
&+T1:<object_name>
&-T2:<object_name>
@constructer...

$<class_name>

Basic example

$Box<T1, T2>
&+T1:item
@constructer()
    &if(item:type == int:type)
        &item = 1
    &elif(item:type == string:type)
        &item = "Hello"
    &else
        &item = NULL
    &endif
@constructer
$Box
&Box<int>:Box1
&Box<string>:Box2
