Built-in functions

$Person
&+string:name
&-int:age
@constructer() #constructer is special function name for initializes object
&name = "John Doe"
&age = 10
@constructer(string:_name, int:_age) #multiple constructers with different definitions are allowed
    &name = _name
    &age = _age

@+set_age(int:_age)
    &age = _age 
@set_age

@+get_age()
    &return:age
@get_age
$Person

&print:The class type is :{Person:type}

:type - static function returns class name

Expected output

The class type is Person
