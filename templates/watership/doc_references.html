Built-in functions

Watership standard library has built-in functions make development process smoother

Class

$Person
&+string:name
&-int:age
@constructer() #constructer is special function name for initializes object
&name = "John Doe"
&age = 10
@constructer(string:_name, int:_age) #multiple constructers with different definitions are allowed
    &name = _name
    &age = _age

@+set_age(int:_age)
    &age = _age 
@set_age

@+get_age()
    &return:age
@get_age
$Person

:type - static function returns class name

Usage:

&print:The class type is :{Person:type}

Expected output

The class type is Person

Array

:sort - sort array members

&array:a = [5,10,3,7,45,12]
&a = a:sort(asc = T) #orders ascending order
&print:{a}

Expected output

3 5 7 10 12 45

:index - array object automatically enumerates it's members. It's useful for iterating through array such as foreach loop

Usage:

 &print:{&a[10]:index} #output: 10

Primitives

:format - returns formatted string value

&int:a = 4
&float:f = 3.1458789
&print:{a:format(5d)}:\n #fixed length 5
&print:{f:format(.2f)}:\n #print 2 digits after floating point

Expected output

00005
3.14

:convert

&int:a = 10
&float:f = 2.156651
&string:s = a converts to 10 as a string
&int:b = f floors the number (2.14 -> 2)
&float:k = a 10 -> 10.0
