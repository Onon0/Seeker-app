Loops

All loops are denoted with % in front of key word. % at the end denotes end of nearest loop

 
 %while(<condition>)
    #do something
 %

 
 &int:a = 0
 &array<string>[3]:arr = ["apple","banana","kiwi"]
 %while(a < 3)
 &print:{arr[a]}: :
 %

Expected output

 apple banana kiwi
