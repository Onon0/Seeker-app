Loops

All loops are denoted with % in front of key word. % at the end denotes end of nearest loop

 
 %while(<condition>)
    #do something
 %

While loop

 
 &int:a = 0
 &array<string>[3]:arr = ["apple","banana","kiwi"]
 %while(a < 3)
 &print:{arr[a]}: :
 &a += 1
 %

Expected output

 apple banana kiwi

For loop

 
 %for(int:a = 0, a < 5, a+=1)
 &print:{a}: :
 %

Expected output

 0 1 2 3 4

Foreach loop

 
 &array<string>[3]:arr = ["apple","banana","kiwi"]
 %foreach(string:a in arr)
 &print:{a:index}: \: :{a}: :
 %

Expected output

 0 : apple 1 : banana 2 : kiwi
