Basic template

@ denotes start of function. function @<function_name> denotes end of function. 

@<function_name>(<type>:<object>, <type>:<object>, ... , <type>:<object>):<return_type optional>
&instruction1
&instruction2
...
&instruction3
@<function_name>

Example code

@add(int:a, int:b):int
&int:c=a+b
&return:c
@add

&print:2 + 3 is :{add(2,3)}
expected out: 
2 + 3 is 5

You can also modify variables by passing the pointer type variable

Pass by pointer example

@change_value(int:a, pointer:b)
&a = 100
&b:value = 100

&int:a
&int:b
&change_value(a,b)
&print:a is :{a}:endl
&print:b is :{b}:endl

Expected output

a is NULL
b is 100
