Pipeline calling

Syntax

<object>:<function1>:<function2>

With Watership language you can create pipeline of functions as shown above. Pipe function is special function that takes return value of previous as input

Basic example

$Person
&+string:name
&-int:age
@constructer() 
    &name = "John Doe"
    &age = 10
@constructer() 
@constructer(string:_name, int:_age) 
    &name = _name
    &age = _age
@constructer() 
@+get_age()
    &return:age
@+increment_age(pipe:_age) pipe is a special keyword that allows pipeline input
    &age = _age + 1
$Person

&Person("Mary Sue", 20):person
person:get_age():increment_age  if all member is pipe type "()" is not need after function 
&print:{person:name}: is :{person:get_age}: years old \n

Expected output

Mary Sue is 21 years old
